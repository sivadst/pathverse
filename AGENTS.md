# PATHVERSE AI ENGINEERING DIRECTIVE

PathVerse AI is a cinematic GPU-accelerated intelligent navigation operating system.

Engineering priorities:
1. performance first
2. scalable architecture
3. GPU rendering
4. reusable systems
5. strict TypeScript
6. production-grade quality
7. cinematic UX
8. maintainability

Core architecture:
- PixiJS/WebGL renderer
- event-driven simulation engine
- telemetry-first instrumentation
- scheduler orchestration
- battle simulation systems
- AI learning visualization

NEVER:
- use placeholder implementations
- degrade architecture quality
- bypass strict typing
- use inefficient array sorting for pathfinding
- place React in rendering hot loops

ALWAYS:
- benchmark performance
- validate builds
- run tests
- optimize rendering
- keep systems modular
